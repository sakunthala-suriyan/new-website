# Sakunthala Portfolio

🌐 **Live Site:** [sakunthala-suriyan.github.io/sakunthala-portfolio](https://sakunthala-suriyan.github.io/sakunthala-portfolio/)

Interactive data-analytics portfolio built with React, Vite, Tailwind CSS, and Framer Motion. Showcases four Power BI dashboards across e-commerce, HR analytics, EV charging infrastructure, and digital payments, plus an ATS-friendly resume.

---

## 🛠 Tech Stack

- **Frontend:** React 19 + TypeScript
- **Build Tool:** Vite 7
- **Styling:** Tailwind CSS 4
- **Animation:** Framer Motion
- **Icons:** Lucide React
- **Deploy:** GitHub Pages (`gh-pages` branch)

## 📊 Featured Projects

| Dashboard | Focus | Tech |
|---|---|---|
| E-Commerce Sales | Revenue, profit, AOV | Power BI, DAX, Star Schema |
| HR Analytics | Attrition, demographics | Power BI, DAX |
| EV Market & Charging | Adoption, geospatial trends | Power BI, Map Visuals |
| PhonePe Digital Payments | FinTech user insights | Power BI, Trend Analysis |
